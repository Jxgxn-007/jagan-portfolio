## ✨ Overview

This repository contains the personal portfolio of **Jagan M**, an Information Technology student at **Mepco Schlenk Engineering College** (Expected graduation 2028).

The portfolio is designed as an immersive, **light-themed 3D interactive space** combining editorial aesthetics, soft studio shadows, and WebGL Three.js interactive geometry.

---

## 🚀 Signature Features

* **🎨 Light Editorial Visual Identity**: Built on a warm ivory canvas (`#F8F7F2`) with crisp white elevated cards (`#FFFFFF`), near-black typography (`#202124`), and vivid cobalt blue accents (`#315CFF`).
* **🧊 Three.js 3D Interactive Hero**: A real-time WebGL scene featuring floating cobalt torus, lavender sphere, soft orange cube, and mint octahedron responding to pointer parallax.
* **⚡ Battery & GPU Optimized**: Uses `IntersectionObserver` to automatically pause the Three.js animation loop when out of viewport, and respects `prefers-reduced-motion`.
* **🤖 Jagan AI Assistant Chatbot**: Integrated on-page chatbot assistant providing verified information about education, technical skills, projects, and resume download.
* **📱 Responsive & Tactile**: Smooth 3D card tilt effects, single-column mobile adaptation (introduction first, portrait second), and zero horizontal overflow.
* **📄 Resume Integration**: Direct ATS-friendly PDF download (`assets/Jagan_M_Resume.pdf`).

## 💻 Local Development

To run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/Jxgxn-007/jagan-portfolio.git

# Navigate to directory
cd jagan-portfolio

# Start a local HTTP server
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
